⑤ 一句话结论

💡 框架的价值 = 工程可靠性，不是诊断智力。
同样的模型，裸协议下强推理模型"越问越偏、忘了下结论"（GLM 完成率 0%），套上框架（原生工具 + 消息管理 + 结构化循环）后 100% 稳定收尾、~12 轮就收敛。而两个强模型框架下准确率都趋同于 ~70%——说明框架没让模型更聪明，只是让它可靠地把该做的事做完。诊断准不准的上限，由模型强弱和病例难度封顶，不由框架决定。而这套结论之所以站得住，是因为量尺本身先跟官方对到了 400/400。
