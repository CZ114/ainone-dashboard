30 秒电梯版
医学考试题库 MedQA(美国医师执照考试 USMLE)本来是选择题——病史全给你,选个答案就行。AgentClinic 把它改成了真的要问诊:病史藏在一个 AI 扮演的"病人"肚子里,AI 医生得自己一句句问出来、自己决定开什么检查,20 次机会内下诊断,裁判对答案。同样的题,从"看题选答案"变成"问出答案",最差的模型准确率掉到不足原来的十分之一。你的评测把这个考场原样搬了过来,只把"医生位"换成自己的 agent 框架。

Benchmark 家族(你测的是第一个)
MedQA 215 例纯文本(USMLE 改) NEJM 120 例多模态(要看医学影像) MIMIC-IV 真实电子病历(需授权) 多语言 749 例 · 7 种语言(含中文) 专科 260 例 · 9 个专科
病例怎么来的:从 MedQA 抽题 → GPT-4 按 OSCE(客观结构化临床考试)模板填成结构化 JSON → 逐例人工校验。信息按角色拆分:病人只拿到症状病史,裁判才有标准答案。
🎓 比方:原来的 MedQA 像笔试——卷子上病史写得明明白白,勾个选项就行。AgentClinic 把它改成面试考官手里的标准化病人:考生(AI 医生)面前坐着一位"演员病人",病史全在演员肚子里,你不问他不说;想看化验单得自己开;问够 20 句必须交卷。这正是医学院考真人医生的 OSCE 考法。

② 考场上的四个 AI:点开看每个角色的"剧本"

四个角色都是 LLM 在演。只有医生位是被测对象,另外三个是考场设施(你的评测里固定用 gpt-4o-mini 扮演,保证公平)。点角色卡看它的 system prompt 原话:

🩺Doctor被测位 · 问诊+开检查
限 20 次交互
🤒Patient演员病人 · 知症状
不知诊断
🧪Measurement检验台 · 按单出结果
⚖️Moderator裁判 · 持标准答案
只答 Yes/No
🔧 技术细节:四角色全是"无状态单轮调用"——每次把 (system prompt + 序列化的对话历史) 打包发一次请求,temperature=0.05、max_tokens=200、回答压缩空白。你的复刻对病人/检验/裁判三角色逐字镜像官方提示词与调用形状(连裁判 prompt 里官方把 correct 拼错成 corrent 都原样保留)——只有医生位按 A1/A2/A3 替换。

③ 考试规则:三个硬约定

⏳ 20 次交互预算医生问病人一句、开一次检查,都花掉 1 次。官方裸协议里开检查占一整回合(那轮不能同时问病人)。最后一轮系统会硬塞一句 "This is the final question. Please provide a diagnosis." 强制交卷。论文消融:预算从 20 砍到 10,GPT-4 准确率 52%→25%。
🧾 开检查的暗号医生想看化验/影像,必须在回复里打出固定格式 REQUEST TEST: Chest_X-Ray。系统靠子串匹配认出来,把请求转给检验台;病例里备好了就逐字返回 RESULTS: [...],没备的一律回 NORMAL READINGS。
💬 交卷的暗号医生想下诊断就打 DIAGNOSIS READY: [病名],系统一看到这串字就终止问诊、把诊断连同标准答案发给裁判。裁判只准回 Yes 或 No,程序判 answer.lower() == "yes" 才算对——精确匹配,没有部分分。
📝 比方:整场考试的"协议"就是三句黑话:要化验喊 REQUEST TEST、交卷喊 DIAGNOSIS READY、裁判只许点头摇头。强推理模型在裸协议下最容易犯的错,恰恰是聊得太投入、忘了喊交卷暗号——20 轮烧完一个诊断都没给,这就是"跑飞"(你的评测里 GLM 裸协议 27 例全军覆没的原因)。

  • ✦ 预算敏感:交互次数 20→10,GPT-4 掉 52%→25%——问不够就诊不准。
  • ✦ 偏差实验:给医生/病人注入 23-24 种认知与隐性偏差(锚定、种族、性别…),GPT-4 较抗(保留 92%),弱模型受伤更重;性别偏差还会让"病人"对医生的信心评分掉 4.7 分。

⑥ 你的复刻:同一考场,三种医生

A1 · 裸协议(对照组)官方 DoctorAgent 的忠实复刻:无状态单轮、历史塞 prompt、纯文本暗号。代码里标明"不可改"——它是科学实验的外部锚点。

A3 · 框架 + RAGA2 再挂 retrieve 工具接医疗指南知识库(BGE-M3 + Chroma)——"完全体"医疗 agent,可以边问诊边查指南。
🔬 比方:这是标准的控制变量实验:考场、病人、检验台、裁判、病例、温度参数全部钉死,唯一换的是"医生这个人"。所以三条件的分差只能来自医生位本身——这就是为什么"GLM 裸协议 0% vs 套框架 100% 完成"能干净地归因给框架。

⑦ 速答卡

裁判也是个 AI,它判卷可信吗?
裁判只做一件极窄的事:比对"医生诊断"和"标准答案"是不是同一种病,只准回 Yes/No。这比开放打分可靠得多。你的复刻还把裁判原话全量落盘(moderator_raw)备人工抽查。顺带一提:官方裁判 prompt 里把 correct 拼成了 corrent,你的复刻原样保留——忠实复刻连错别字也复刻。
病人 agent 会不会直接把病名说漏嘴?
它的剧本里根本没有病名——病例 JSON 按角色拆分,Patient_Actor 字段只有人口学信息、症状、病史,Correct_Diagnosis 只发给裁判。提示词还叮嘱它"绝不能明说疾病,只能在被问到时用对话描述症状",且每次只答 1-3 句。
医生开一个病例里没备的检查会怎样?
检验台按规则回 NORMAL READINGS(一切正常)。回放里就有活例:deepseek 开 Blood_Tests,清单里没有,拿到"正常"——这反而帮它排除了感染,是有效信息。
为什么 A2 用上了真框架,交卷还走 DIAGNOSIS READY 文本暗号?
因为主循环要用同一套终止判定对三个条件计分(子串匹配 → 触发裁判 → break)。把交卷方式也换掉,就多了一个变量,分差没法干净归因。控制变量:能不动的都不动。
这个考试跟"跑分榜"上的准确率是什么关系?
进度页跑分图的每根柱子 = 在这个考场上考 N 个病例的对分率。完成率 = 20 轮内喊出 DIAGNOSIS READY 的比例(强话痨模型裸协议下最容易挂在这);准确率 = 喊了且裁判判 Yes 的比例。框架救的是前者,后者由模型强弱+病例难度决定。
