📦 一条 JSON 的往返 — 从你提问到看见回答

这次不讲房子（架构），只跟着数据本身走。先记住三条规矩，整个流程的逻辑就这三句话：

规矩一：一去，多回。
你的问题打包成 1 个去程包发出；回来的不是一个包，是一串回程行——沿着同一根保持打开的管子，做好一件回一行。
规矩二：全程都是 JSON。
前端↔后端、后端↔LLM、后端↔工具，说的全是同一种话：「键: 值」的小纸条。没有第二种格式。
规矩三：分发 = 认 type 字段。
每行回程 JSON 都带一个 type。前端拆开只看它：tool_call→画工具卡，delta→写字，done→收工。一个 switch，没有别的魔法。
