# AinOne 全栈 + Agent 项目制学习中心

这组材料把当前仓库当作唯一主案例，用真实代码补齐全栈、Agent 工程和面试表达。目标不是再做一个教程 Demo，而是做到：

1. 能从 ESP32 数据进入系统开始，讲到 React 页面如何完成一次渲染。
2. 能从聊天请求开始，讲到 Agent、工具、审批、RAG、工作流和会话持久化。
3. 能区分自己已实现、只写在设计文档、已过时说明和仍未实现的部分。
4. 能把真实面试中出现过的问题，逐一映射回自己的代码。

## 证据边界

- **已实现**：当前源码中能定位到实现。
- **部分实现**：主链路存在，但测试、容错、部署或文档不完整。
- **设计/历史**：只在规范、旧 README 或 journey 中出现，不能当作当前运行事实。
- **待验证**：需要硬件、模型密钥或运行时环境才能证明。
- **面经证据**：只把明确自述为面试/笔试出现的问题纳入题库；JD、培训题库和模型生成题不进入核心统计。

## 推荐使用方式

每次学习固定走五步：`读源码 → 手画数据流 → 口述设计取舍 → 做一个小实验/测试 → 回答对应面试题`。课程修改应放在单独分支或实验目录，不直接破坏当前可运行基线。
