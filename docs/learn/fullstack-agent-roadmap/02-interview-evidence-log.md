# 02｜真实面经证据库（持续维护）

## 收录规则

本文件不是通用八股题库，只记录公开页面中明确自述为面试、笔试、手撕或多场面试复盘的问题。

### 证据等级

- `A`：候选人原始面经，包含公司/岗位/轮次或明确的现场问题。
- `B`：候选人多场面试回顾或可定位的二次整理，问题可信但无法逐题绑定单场。
- `C`：培训题库、经验文章、JD 推断、营销内容；只进入观察区，不计入高频。
- `X`：无公开正文、无法确认岗位、疑似生成题或无来源；不收录。

### 高频定义

- `高频`：同一问题簇至少出现在 2 个独立 `A` 来源。
- `出现过`：只有 1 个 `A` 来源，也保留，但不宣传为高频。
- 问题采用短句转述，避免整段复制原帖；含义必须与来源一致。

## 与本项目最匹配的首批 20 题

按学习顺序：`PA03 → BE01 → FS01 → FS02 → FS04 → AG01 → TL01 → TL02 → TL04 → AG03 → AG05 → MR01 → MR02 → MR03 → RG01 → RG02 → RG06 → AG06 → OE01 → OE02`。

每题的合格答案必须包含：

1. 一句定义。
2. 当前项目的真实实现路径。
3. 为什么这样设计。
